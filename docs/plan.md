# First usable slice

One native Rust crate. Append-only JSONL events are authoritative; state and topology are projections. UI effects cannot create success. CLI execution and provider streaming are separate from execution policy. Pipe sessions persist across turns; terminal emulation and PTYs are deferred explicitly.

1. Typed events, deterministic reducer, exclusive run creation, artifact storage, demo and themed TUI.
2. OpenAI-compatible Chat Completions and native Anthropic Messages SSE; direct/shell tools and supervised persistent pipe sessions; bounded capture.
3. Revision invalidation, five Rewire operations, constraint pinning, topology lenses, explicit YOLO, context/config inspectors and read-only review.
4. Boundary tests, formatter, Clippy, offline workflow, runtime commands, terminal inspection, multi-OS CI.

Acceptance: deterministic demo records real repair transitions and retained artifacts; fixture HTTP model loops invoke a harmless real command; cancellation is observed; damaged journals retain valid prefixes; historical rendering has no executor; every shipped key works or says unavailable. Live credentials are optional and live checks are reported separately.

Shared module contracts are agreed before delegated changes. Provider owns protocol, process owns lifetimes; controller alone authorizes dispatch and user autonomy changes.

# friendo v0.1.0

First usable native Rust agent console with a Ratatui interface, durable journal and artifacts, inspectable model context, and correction/repair controls.

- Streaming OpenAI-compatible Chat Completions and native Anthropic Messages, with explicit model configuration and environment credential references.
- Direct argv execution and persistent pipe sessions, bounded output retention, interruption, and native descendant supervision.
- Credential-free synthetic demo, topology and provenance views, exact outbound context, historical review, and NORMAL/YOLO controls.
- Default execution admission limited to `echo`, `pwd`, and `whoami`, with shell evaluation disabled. The QA helper requires explicit opt-in.
- Native Linux/macOS/Windows tests and packaged-binary smoke checks. The bounded live Anthropic model/tool verification is documented separately in the source.

Choose the archive for Linux x86-64, macOS Apple Silicon, macOS Intel, or Windows x86-64, verify its SHA-256 entry, extract it, and run `friendo doctor` or `friendo demo`. Packages include the executable, LICENSE, README, an example configuration, and exact source identity. No credentials or personal provider configuration are bundled.

Linux requires glibc 2.35 or newer. macOS builds target macOS 13 and are tested on macOS 15; they are unsigned and not notarized. Windows x64 MSVC builds use a static C runtime and are tested on Windows Server 2022; they are unsigned. See [release instructions](https://github.com/rainmana/friendo/blob/v0.1.0/docs/releases.md) for checksums, targets, and source.

This is an early, narrow version. Sessions use pipes rather than terminal emulation. Execution admission is not an OS sandbox. Arbitrary natural-language constraints and semantic disagreement are not automatically enforceable; disk resume, rollback, migration, and discovery are unavailable. See the tagged README and build-status documentation for evidence and limits. No universal model compatibility, production-readiness, signing, or reproducible-build claim is made.

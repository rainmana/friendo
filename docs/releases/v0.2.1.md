# friendo v0.2.1

This patch makes everyday Chat input more reliable while preserving the Chat/Expert layouts, live topology, and neon presentation introduced in v0.2.0.

- **Busy sends keep your draft.** Enter during an active turn no longer silently corrects the goal, cancels work, and clears the unsent message. The draft stays editable and the journal stays unchanged. Wait, or interrupt with Ctrl-C, then press Enter again. Nothing is queued or retried automatically.
- **Input guidance stays visible.** Streaming updates no longer erase the explanation beside an unsent draft. Opening context with F5 and closing it with Enter preserves both draft and notice. Expert's composer has the same protection.
- **Corrections explain the next step.** A Rewire correction saved while a turn stops keeps its `/continue` instruction visible until the user acts.
- **Color troubleshooting is documented.** A nonempty `NO_COLOR` environment variable suppresses Crossterm colors even when TOML enables them. The documented process-local override restores the configured palette; this patch does not change the theme or global terminal settings.

The reliability feature passed native CI with 102 Rust tests on Linux/macOS and 100 platform-specific tests on Windows. Both Unix terminal journeys passed, including journal-preserving rejection and exactly one explicitly resent request. These fixtures do not contact Anthropic. The separate live Anthropic check on November 14 verified installed **v0.2.0**, not a new v0.2.1 live-provider run. See [build status](https://github.com/rainmana/friendo/blob/v0.2.1/docs/build-status.md) for evidence and scope.

Existing configuration and credential references remain compatible. NORMAL remains the default, shell execution remains disabled by default, and executable admission remains `echo`, `pwd`, and `whoami`. Provider protocols, process behavior, schema-1 journals, and Protobuf are unchanged. Publishing this release does not replace an installed binary.
